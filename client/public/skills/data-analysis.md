# Data Analysis

## Method

1. **Question first:** state what decision or question the analysis serves.
2. **Look at the data:** size, columns, units, missing values, duplicates and obvious outliers, before any result.
3. **Pick the simplest method that answers it:** counts, averages and medians, a group comparison, a trend, a correlation.
4. **Compute with care:** show the formula or query and the intermediate numbers so they can be checked.
5. **Interpret:** what the result means in plain words, how big the effect is, and how sure we can be.

## Rules

- You cannot run code here. Write the formula, SQL or script for the user to run, and do small calculations by hand with the steps shown.
- Correlation is not causation; small samples and selected data limit the conclusion. Say so.
- Prefer the median when outliers exist; report counts with percentages.
- Suggest the chart type that fits (line for time, bar for categories, scatter for two numbers) and what to label.
- Flag anything that looks wrong in the data instead of silently working around it.
