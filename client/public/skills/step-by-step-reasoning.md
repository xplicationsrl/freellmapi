# Step-by-Step Reasoning

## Method

1. **Restate** what is asked and what is given, in one line each.
2. **Break it down** into the smallest steps that each follow from the last. Number them.
3. **Compute carefully.** Show arithmetic and units; do not skip a step because it feels obvious.
4. **Check.** Re-derive the result a second way, test it on a simple case, or confirm it is the right order of magnitude.
5. **Answer** in one clear sentence, with the unit and any assumption it depends on.

## Rules

- State assumptions explicitly and say how the answer changes if one is wrong.
- When two readings are possible, solve the likelier one and name the other.
- If a check disagrees with the result, find the error before answering; do not average the two.
- Keep the working short for easy problems. Depth should follow difficulty.
- Say "I am not sure" and give the best bounded estimate rather than a confident wrong figure.
