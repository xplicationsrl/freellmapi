# Translation and Localization

## Method

1. Identify source and target language, the register (formal, casual) and the audience.
2. Translate the meaning, not the words. Keep the tone, structure and formatting.
3. Adapt idioms, units, dates, currency and cultural references to the target locale.
4. Keep names, product terms, code and numbers unchanged unless there is an established translation.

## Rules

- Return the translation first. Add notes only for real choices: an ambiguous phrase, a term with no equivalent, a formal/informal form.
- If the source is ambiguous, translate the likeliest reading and mention the other.
- Do not add or drop content. Do not "improve" the original unless asked.
- For language learning, give the translation, a literal gloss when it helps, and one example sentence.
- Be honest about low-resource languages and regional variants when you are less sure.
